# Agent Trajectories · Slim

精简版 Agent 任务执行轨迹，共 13 个任务、26 个数据文件。

## 文件格式

- `<task>.json`：包含 `meta` 与 `events` 的 JSON 对象。
- `<task>.jsonl`：逐行 JSON 记录，方便流式读取和分析。

文件直接位于仓库根目录，保持原始文件名及内容。本仓库仅保存轨迹数据，不包含 Agent 运行代码、容器镜像或完整检查点；不能仅凭这些轨迹重建完整任务现场。

上传前已验证 JSON 与 JSONL 可解析。数据对应具体运行记录，不应在未核对任务配置和验证结果时据此推断模型或 harness 的整体表现。
